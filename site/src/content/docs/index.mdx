This project documents and automates what we learned while reverse-engineering the **CMF Watch Pro 2**
(firmware `1.0.0.73`, board `JX402`, Actions ATS3089C). It is not an official Nothing/CMF project.

The practical results so far:

- Parse, verify, rebuild and patch AOTA firmware images without touching the watch.
- Parse and rebuild SDFS partitions, RES picture/string pools, STY UI bundles and WFDL watch faces.
- Decode, edit and re-encode `.ajs` animations; a 202-frame Bad Apple proof of concept was flashed and verified.
- Authenticate over BLE, talk to the shell channel, upload/delete watch faces, and run a full AOTA
  firmware update over BLE.

:::caution[Read this first]
Firmware flashing can brick a watch. There is no confirmed hardware recovery path for every failure.
The tools are provided for research and interoperability; use them on hardware you own and can afford
to lose. Read [Limitations & risks](/cmf-watch-utils/overview/limitations/) before flashing anything.
:::

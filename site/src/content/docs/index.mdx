CMF Watch Utils is an unofficial interoperability project. It provides an offline toolkit for the
firmware containers used by CMF Watch devices, a Python client for the watch's BLE services,
and the research notes behind them.

The project is device-scoped: each supported model has its own section with its own
protocol details, format notes and verified results. Shared tooling and general documentation
live at the top level, so new devices can be added without duplicating the tools.

:::caution[Risk]
Firmware flashing can leave a watch unbootable, and no universal recovery path has been proven
for every failure mode. The tooling exists for research, interoperability and hardware that is
owned and whose loss is acceptable. The device section documents the specific risks.
:::

## Project contents

| Area | Description |
|---|---|
| [Toolkit](/tooling/fwkit/) | `fwkit` — parse, rebuild and patch AOTA, SDFS, RES, STY, WFDL, AJS and picture containers offline |
| [BLE tooling](/tooling/ble-tools/) | `cmf_watch.py`, `ota_client.py` — pairing, shell commands, watch-face upload, firmware OTA |
| [Device research](/devices/cmf-watch-pro-2/) | Protocol details, format layouts, verified results and known gaps per device |
| [Dumps](/dumps/) | Firmware manifests, hashes and downloadable images |
| [Agent context](/ai/context/) | A compact briefing for AI coding agents |

The project was built from a private working directory containing roughly 2.7 GB of material.
This page lists every group of artifacts from that directory, whether it is published here, and
why. The goal is that a reader can reproduce the results without access to anything outside
this repository.

## Published

| Area | Location | Contents |
|---|---|---|
| Container toolkit | `tooling/src/fwkit/` | AOTA, SDFS, RES, picture, STY, WFDL, AJS, LZ4, PNG, ACTH parsers and writers, plus the CLI |
| Regression suite | `tooling/tests/selftest.py` | Round-trip checks for every container |
| Ghidra helpers | `tooling/ghidra_scripts/` | 40 scripts for function, xref, string, immediate and OTA analysis |
| Redaction tool | `tooling/redact.py` | Removes device identifiers from logs and traces |
| Live BLE CLI | `tools/cmf_watch.py` | Pairing, shell commands, dial management, OTA experiments |
| OTA client | `tools/ota_client.py` | The verified full-image OTA flow |
| Other live tools | `tools/spp_ota.py`, `tools/rfcomm.py`, `tools/maputil.py` | SPP experiments, RFCOMM helper, offset helpers |
| Legacy scripts | `tools/legacy/` | The original standalone unpack, decompress, xref and string tools |
| Experiment probes | `tools/experiments/` | 50 one-off probes that established the pairing and OTA behaviour |
| Firmware images | `dumps/binaries/` | Stock image, rebuilt proof-of-concept image, extracted `app.bin` (LFS) |
| Analysis output | `dumps/analysis/` | Function list, function map, strings, string xrefs, block list, 231 decompiled function listings, Ghidra run logs |
| Run logs | `dumps/logs/` | The OTA client logs of the successful and failed flashes (redacted) |
| Protocol traces | `dumps/traces/` | Captured notification frames used to map the protocol |
| Samples | `dumps/samples/` | A STY bundle, decoded picture samples, one WFDL watch-face package |
| Manifests | `dumps/manifests/` | Sizes, hashes, header fields and per-entry CRC status |
| Documentation | `site/` | 32 pages, per device, with the full protocol and format notes |

## Omitted, with reasons

| Local material | Reason |
|---|---|
| Pairing state (`tools/.watch_state.json`) | Contains the pairing secret and the authkey. Replaced by the `pair` command, which recreates it. |
| Activity data (`activity.json`, `gps_track.csv`, `gps_track.geojson`, `gps_map.html`, `gps_report.py`) | Personal movement and health data. The activity format is not part of the research question. |
| Device debug logs (`flog1.log`, `flog2.log`, `nlog0.log`, `nlog1.log`, 10 MB each) | 34 MB of system logs containing the MAC address, serial number and processor id on thousands of lines. The protocol facts they contain are already extracted into the documentation. |
| OTA byte stream (`ota_extract.txt`, 106 MB) | A raw hex dump of one transfer. It is reproducible with `ota_client.py -v` and adds 106 MB to the clone for no new information. |
| Screenshot and unrelated logs (`screen.png`, `hookout.log`, `trustout.log`, `mounts.txt`, `libmedia.so`) | Personal screen content and artifacts of unrelated projects. |
| Local run wrappers (`run_mod3.cmd`, `run_pwned.cmd`) | Batch wrappers with absolute local paths. The equivalent commands are documented in the guides. |
| Extracted firmware trees (`firmware/unpacked/`, `firmware/fwtest/`, `firmware/tree/`) | Byte-for-byte derivable from the published image with `fwkit unpack`. |
| Edit-test images (`app_edit_test.bin`, `res_edit_test.bin`, `sty_edit_test.bin`, `logo_edit_test.bin`, 56 MB each) | Round-trip proofs. The same proof is produced by the selftest and by `fwkit pack`. |
| The proof-of-concept animation (`badapple_poc.ajs`, 756 KB) and its contact sheet | Third-party frames; the same content is already inside the published proof-of-concept image. |
| Ghidra projects (`fwsdk/proj073`, `ghidra_proj`, `proj_test`) | Binary project files, tens of megabytes, regenerated by importing `app.bin`. The knowledge extracted from them is published as text under `dumps/analysis/`. |
| The phone app analysis (`nothingx/`, `blutter/`, `base_decoded/`, `base.apk`) | 2.7 GB of Dart AOT analysis of the Nothing X app. It was the reference client for the OTA handshake, but it belongs to a different device and to third-party application code. |
| Third-party reference implementations (`refs/fmc`, `refs/cmf-ble`) | Vendored copies of other projects. `freethinkel/fmc` is credited in the licence and attribution section instead. |
| The app asset database (`watchfaces/nothing_x.db`, 4.2 MB) | The app's asset database with vendor assets and unrelated entries. |
| The firmware image of the earlier `pwned` attempt | An intermediate rollback image from an unsuccessful attempt; it is superseded by the published proof-of-concept image. |
| Watch-face packages `wf2.bin`, `wf3.bin` | Vendor assets used only for comparison; `wf1.bin` is published as the sample used in the guide. |
| Other CMF Watch firmware and unrelated projects in the workspace (`evox_*`, `kernelport`, `kmod`, `npibridge`, `onelots_wiki`, `whatsapp_decoded`) | Unrelated research, kept out of this repository. |

## What a reader still needs

Nothing beyond this repository and the public internet:

- **Python 3.12 and uv** for the tooling. `uv sync` installs everything.
- **A device** for the live paths. The read-only paths (`scan`, `info`, `at`, `ota-state`) work
  against any unit of the same model.
- **The published firmware image** for the offline paths. It is included under `dumps/binaries/`.
- **Ghidra** for the static analysis pages. The scripts are included; the app image is published.

## Reproducing each result

| Result | Command |
|---|---|
| Stock image parses and every CRC matches | `uv run fwkit verify dumps/binaries/firmware/JX402_V1.0.0.73.bin` |
| Container round-trips are byte-identical | `uv run python tooling/tests/selftest.py dumps/binaries/firmware/JX402_V1.0.0.73.bin` |
| The `.ajs` proof of concept round-trips | `uv run fwkit ajs-info dumps/binaries/app/app_073.bin` for the app; the animation is inside the published proof-of-concept image |
| The animation layout | `uv run fwkit sdfs-extract dumps/binaries/firmware/JX402_V1.0.0.73_badapple9.bin work/res_e` |
| The analysis outputs | `fwkit` plus the Ghidra scripts against `dumps/binaries/app/app_073.bin` |
| The OTA flow | The device section of this documentation, with `tools/ota_client.py` |
